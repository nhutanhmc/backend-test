## 1. Scrape ⇒ Markdown (~3 h)
**Yêu cầu**: Lấy ≥ 30 bài viết từ website OptiSigns, chuyển thành Markdown (text dễ đọc), lưu file.

**Tại sao làm vậy?** Website có data hỗn loạn (HTML). Chúng ta "scrape" (cào) data sạch, chuẩn hóa thành Markdown để AI dễ hiểu. Dùng API (giao diện web) thay vì scrape HTML phức tạp.

**Code tương ứng**:
- `scraper.py`:
  - `scrape_data()` (lines 12-66): Hàm chính. Dùng thư viện `requests` (như browser) call API Zendesk (địa chỉ web lấy data). Nhận JSON (dữ liệu structured), loop qua 30 bài, chuyển HTML → Markdown bằng `markdownify` (thư viện chuyển đổi). Lưu file text vào thư mục `data/`. Tại sao? API trả data sạch, không cần parse HTML thủ công.
  - `clean_filename()` (lines 8-10): Làm tên file an toàn (bỏ ký tự lạ như / hoặc :). Tại sao? Tránh lỗi khi lưu file trên Windows/Linux.
  - Excerpt: `response = requests.get(ZENDESK_URL)` (line 15) – Gửi request lấy data. `markdown_body = md(html_body)` (line 35) – Chuyển HTML thành Markdown. `with open(filename, "w")` (line 40) – Lưu file text.

## 2. Build Assistant & Programmatically Load Vector Store (~2 h)
**Yêu cầu**: Tạo AI bot (Assistant) trên OpenAI, upload files để bot học, log số file.

**Tại sao làm vậy?** AI cần "học" data để trả lời. Upload files vào Vector Store (kho lưu vector – đại diện text). Assistant dùng data đó trả lời. Làm programmatic (code) thay UI để tự động.

**Code tương ứng**:
- `ai_manager.py`:
  - `setup_ai_backend()` (lines 15-40): Tạo Vector Store (kho chứa files) và Assistant (bot AI) qua OpenAI API. Tại sao? Bot cần kho data và prompt (hướng dẫn). Dùng `client.vector_stores.create` (tạo kho), `client.beta.assistants.create` (tạo bot với prompt cố định).
  - `upload_single_file()` (lines 50-75): Upload 1 file lên OpenAI cloud (`client.files.create`), rồi link vào Vector Store (`client.vector_stores.files.create`). Tại sao? OpenAI cần files trên cloud để process. Upload từng file để track ID (mã định danh).
  - Excerpt: `vector_store = client.vector_stores.create(name=VECTOR_STORE_NAME)` (line 20) – Tạo kho. `assistant = client.beta.assistants.create(...)` (lines 23-30) – Tạo bot với prompt.
- `main.py`:
  - Processing loop (lines 110-150): Check file mới/cũ, call upload, log số lượng. Tại sao? Chỉ upload thay đổi để tiết kiệm tiền/API calls.

## 3. Deploy Scraper as Daily Job (~2 h)
**Yêu cầu**: Chạy code hàng ngày, detect thay đổi, log.

**Tại sao làm vậy?** Data website thay đổi. Chạy daily để update AI. Dùng Docker để dễ deploy (chạy mọi nơi), cron để tự động.

**Code tương ứng**:
- `main.py`:
  - `main()` (lines 40-180): Orchestrator (điều phối). Load state (trạng thái trước), setup nếu thiếu, scrape, process, save state. Tại sao? Wrap tất cả thành 1 script chạy 1 lần.
  - `calculate_md5()` (lines 15-25): Tính hash (mã băm) của file. Tại sao? So sánh hash để biết file có thay đổi (nhanh, không đọc toàn bộ).
  - `load_state()` / `save_state()` (lines 27-55): Đọc/ghi JSON lưu IDs và hashes. Tại sao? "Nhớ" files đã upload, tránh duplicate.
  - Excerpt: `if not is_existing: ... new_id = ai_manager.upload_single_file()` (lines 120-125) – Upload mới. Stats logging (lines 160-170) – Báo cáo số file.
- `Dockerfile` (lines 1-10): File build container. Dùng Python image, copy code, run `python main.py`. Tại sao? Containerize để chạy trên server mà không cài Python.
- VPS Cron: Setup ngoài code, chạy `docker run` daily. Tại sao? Tự động, không manual.
